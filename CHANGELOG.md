# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-01

### Added
- Initial release

### Features
- Length converter (meters, kilometers, inches, feet, miles and more)
- Mass converter (kilograms, grams, pounds, ounces and more)
- Temperature converter (Celsius, Fahrenheit, Kelvin and more)
- Time converter (seconds, minutes, hours, days and more)
- Data converter (bytes, kilobytes, megabytes, gigabytes and more)
- Number system converter (decimal, binary, octal, hexadecimal and more)
- Discount calculator (find discounted prices and savings)
- Power calculator (power and energy calculations)
- Text editor and counter

### Enhancements
- Real-time conversion while typing
- Clean glass-morphism UI with CSS variables
- Fully responsive design (mobile, tablet, desktop)
- Progressive Web App support (installable, offline via service worker)
- SEO meta tags and Open Graph images on every page
- Netlify hosting with redirects, sitemap, and robots.txt
